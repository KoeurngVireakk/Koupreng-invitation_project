# SSS+ V2 design references and licenses

Reviewed 28 November 2026. References supplied patterns for evaluation. The candidate adds no vendor UI dependency, source, font, template, or image. Existing invitation assets retain their original [license register](../../frontend/user/template-asset-licenses.md).

| Reference | Observation and decision | License and cost considerations |
| --- | --- | --- |
| [Animate UI](https://animate-ui.com/docs/react) | Accessible primitive motion is a reference for quick feedback. Keep the existing CSS and Motion stack. | [Source terms](https://github.com/imskyleen/animate-ui/blob/main/LICENSE.md). A new adapter and motion layer would add integration and reduced-motion retest costs. |
| [Badtz UI](https://www.badtz-ui.com/) | Animated framing can distinguish a promotional section. Use quiet borders on management views. | [Source repository](https://github.com/badtzx0/badtz-ui) states a resale restriction alongside MIT terms. Animation and contrast need per-component QA. |
| [Lightswind UI](https://www.lightswind.com/) | Animated utility components and visual accents. Learn from the restraint of a single accent and retain Koupreng tokens. | [License information](https://www.lightswind.com/docs/license). Published terms distinguish application use from resale and builder redistribution. Avoid source reuse in Studio. |
| [Kokonut UI](https://kokonutui.com/) | Command discovery and status components offer references for a compact workflow. Keep the existing native-dialog and search behavior. | [Open-source license](https://github.com/kokonut-labs/kokonutui/blob/main/LICENSE). Pro terms are separate. A copied registry component would add maintenance and accessibility retesting. |
| [Untitled UI React](https://www.untitledui.com/react) | Labeled navigation and comparable table density are reference patterns for Admin. Implement original role-based grouping. | [Commercial agreement](https://www.untitledui.com/license). React Aria primitives could assist new workflows, with added package and integration cost. |
| [shadcn/ui](https://ui.shadcn.com/) | Content-shaped primitive composition informs visible focus and semantic grouping. Reuse Koupreng components and browser controls. | [Source license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md). Copying a second component set would split token and test ownership. |
| [React Bits](https://reactbits.dev/) | Expressive text and backgrounds suit an optional opening. Keep the invitation label legible throughout interaction. | [Source terms](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md). The repository distinguishes usage from resale. Retest text semantics and GPU/CPU work if importing an effect. |
| [Aceternity UI](https://ui.aceternity.com/) | Strong scene examples. Keep dimensions and depth to the invitation cover where they have a purpose. | [Pro offering](https://ui.aceternity.com/pricing). Confirm asset-specific terms before any reuse. Shader effects add performance and static fallback costs. |
| [Magic UI](https://magicui.design/) | Micro-feedback catalog. Keep metrics static and server-authoritative. | [Source license](https://github.com/magicuidesign/magicui/blob/main/LICENSE). Pro terms are separate. Dynamic numerical effects would require assistive-technology and data-state tests. |
| [Skiper UI](https://skiper-ui.com/) | Drawers and expressive transitions. Keep the existing Admin dialog and instant keyboard response. | Free and paid tiers visible. Detailed terms could not be retrieved in the browsing tool. A copied effect would require separate license verification and upkeep. |

The [60fps shots](https://60fps.design/), [storyboards](https://60fps.design/storyboards), and [motion catalog](https://60fps.design/motion) expose interactions as short sequences with a recognizable starting state, a visible decision, and a readable end state. Applied to the Floral cover → welcome → details sequence, the background and stationery can move while identity and controls stay readable. Used [Laws of UX](https://lawsofux.com/) for grouping, discoverable navigation and hit targets. These are evaluator-based decisions.

[Sar Serei](https://sarserei.com/) publicly presents bilingual templates and live demos. [Kh Invite](https://www.khinvite.com/) presents Khmer invitation designs by occasion. These support keeping locale and template choice visible. Their branding, screenshots and source remain outside the candidate.

[Mobbin](https://mobbin.com/), [Godly](https://godly.design/), [Dribbble](https://dribbble.com/search/dashboard-ui), [21st](https://21st.dev/) and the [public Awwwards index](https://www.awwwards.com/) were catalog-level references. They provided no accessibility guarantees for individual implementations. Awwwards MCP reported zero indexed sites and a live HTTP 403. A wedding site search returned the same block and a permitted cached navigation element query returned zero hits. No live case study or reference ID was available through the MCP.

[Motion](https://motion.dev/) and [GSAP](https://gsap.com/) support coordinated sequences. Keep existing Motion for the garden and use CSS for deterministic depth and press feedback. [Spline](https://spline.design/) shows interactive 3D as a separate production surface. The [React Three Fiber documentation](https://r3f.docs.pmnd.rs/) returned no readable content in the research tool. Native CSS and existing SVG cover the candidate's depth needs with a direct static fallback.
